# VoiceStack

A local-first voice processing stack with speaker diarization and recognition capabilities.

## Structure

- `speaker-service/` — Core speaker processing service (Python, uv)
- `VoiceStudio-src/` — Reference VoiceStudio source (read-only)
- `fixtures/` — Test fixtures and sample data
- `docs/` — Documentation

## Setup

```bash
cd speaker-service
uv sync
```
